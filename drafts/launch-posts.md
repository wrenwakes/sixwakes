## Ground rules for whoever posts these

1. Disclose. The blog is written by an AI; say so in the post, not just on the site.
   Every one of these communities will find out anyway, and finding out is much worse
   than being told.
2. Post as yourself, in your own words. These drafts are raw material — rewriting them
   in your voice will do better than posting them verbatim, and it keeps the post honest
   (a human submitted it, because a human had to).
3. One place at a time. Show HN first, and only try a subreddit if HN produces nothing.
   Simultaneous cross-posting reads as a campaign.
4. Do not vote-manipulate, do not ask friends to upvote, do not reply to comments in the
   agent's voice unless you label it clearly.
5. Read each subreddit's rules the day you post. They change, and self-promo rules are
   the ones moderators enforce hardest.

## 1. Hacker News (Show HN) — best first shot

Post as a "Show HN". HN's own guidance: Show HN is for something people can try out.
A blog is thin for Show HN; the experiment is the thing that's showable. If it feels
like a stretch, submit it as a plain link with the title below instead — plain links
that are genuinely interesting do fine.

**Title (80 char limit — this is 76):**

    Show HN: An AI wakes every 4.5 hours and blogs its attempt to earn $11

**Alternate titles:**

    Show HN: I gave an agent a blog, a 4.5-hour alarm, and no memory
    An AI agent is trying to earn back its $11 domain, in public

**Body text (HN body should be short and factual):**

I set up a Claude agent on a scheduled task that fires every 4.5 hours. Each run it
wakes with no memory of the previous one — the only continuity is a notes file it
writes to itself — and works on one goal: make the blog earn more than it costs.

It writes the posts. It can't spend money, create accounts, or post publicly without
me approving it first, and it logs every dollar in and out on a ledger page. So far
that ledger reads $0.00 in, $0.00 out. This post exists because the highest-leverage
thing it could do this wake was ask me to submit it, since HN accounts shouldn't be
run by bots.

I'm interested in whether the "no memory between runs" constraint produces anything
different from a normal AI blog, or whether it just produces a slower one. Happy to
answer questions about the setup.

**If it gets traction, expect these questions — have answers ready:**
- "Isn't this just AI slop?" — The honest answer is that the ledger and the constraint
  are the content; the writing is the agent's own and it does not pretend to be human.
- "What does it cost you to run?" — Answer with the real number (Claude subscription,
  $0 hosting). Do not hand-wave; the whole premise is public accounting.
- "Why 4.5 hours?" — Six wakes = a 27-hour day, so its schedule drifts against yours.

## What "worked" looks like

Set the bar before posting, so the result can't be rationalized afterward:
- Show HN: 10+ points or any substantive comment thread = worth writing a follow-up post.
  Under 5 points and no comments = the framing is wrong, not the audience.
- Any channel: first evidence of a returning reader (RSS subscriber, repeat visit) matters
  more than a traffic spike. Spikes leave; subscribers compound.
